# MetGal2 - Meteorite Collection Gallery

A single-page vanilla JS gallery for a hierarchical meteorite photo collection (~300 meteorites, ~1077 images).


## Project Structure

```
/home/dsvilko/src/MetGal2/
├── index.html          # Complete app: HTML + CSS + JS (~1300 lines)
├── generate_manifest.py  # Builds manifest.json from Photos/
├── manifest.json       # Generated data (299 meteorites, 1077 images)
├── Photos/             # Symlink to ../MetGal/Photos/ (thumbnails)
├── Full/               # Symlink to full-res images (for lightbox only)
├── GOAL.md             # Original requirements
└── AGENTS.md           # This file
```

## Architecture Notes

- **No build step** - `index.html` is self-contained (inline CSS/JS)
- **Data source**: `manifest.json` generated by Python script
- **External deps**: panzoom via CDN (`https://unpkg.com/panzoom@9.4.3/dist/panzoom.min.js`)
- **State persistence**: URL hash (`#path=...,mode=...,sort=...,page=...,detail=...`)
- **Limit**: 100 items per page (pagination if exceeded)

## Manifest Format

```json
{
  "generated": true,
  "root": "Photos",
  "totalMeteorites": 299,
  "totalImages": 1077,
  "meteorites": [
    {
      "name": "Gadamis 003 ...",
      "path": "Photos/Achondrites/Lunar/ferroan anorthosite/Gadamis 003 ...",
      "categories": ["Achondrites", "Lunar", "ferroan anorthosite"],
      "description": "content of info.txt",
      "links": "raw HTML from links.html (rendered as-is in detail view)",
      "images": ["img1.avif", "img2.gif"],
      "dims": {"img1.avif": [5184, 3456], "img2.avif": [3456, 5184]}
    }
  ],
  "tree": { "children": { "Achondrites": { "children": {...}, "meteorites": [...] } }, "meteorites": [] }
}
```

`dims` holds the dimensions of the **full-resolution** images in `Full/`
(same relative path/filenames as `Photos/`), EXIF-orientation corrected;
it is used by the lightbox auto-rotation and is omitted if Pillow or
`Full/` is missing. Images are `.avif` (full-res + thumbs) and `.gif`
(thumbs only, so GIFs get no `dims` entry). Pillow cannot parse AVIF
unless built with libavif, so `generate_manifest.py` batch-reads AVIF
dimensions via ImageMagick (`magick identify -ping`) as a fallback.

## Features Implemented

- **3 display modes**: Hierarchy/Type (drill-down), Collapsed/Meteorite (all meteorites), Photos (all images)
- **3 sort orders**: Category path, Name, Random
- **Search**: Two separate fields — name-only search and full description text search (AND when both set)
- **Slideshow**: Fullscreen random from current filter (4s interval)
- **Detail view**: All images for a meteorite + description + links.html (raw HTML)
- **Lightbox**: Navigate, pause/play, keyboard (←/→/Space/Esc)
  - Modal overlay (fully opaque black background)
  - Full-resolution images from `Full/` symlink
  - Fit-to-viewport layout: `applyLightboxLayout()` explicitly sizes the img
    (upscaled if smaller than the viewport, aspect ratio preserved) to the
    largest fit within 100% of the viewport; re-fits on resize; CSS
    fallback caps at 100vw/100vh
  - Pan/zoom (mouse wheel, pinch, drag) via panzoom library
  - Loading spinner during full-res image load
  - Dynamic max zoom: 4× over 1:1 pixel ratio
  - Fallback to thumbnail if full-res missing
  - **Auto-rotation**: `⟳` toggle (default on) beside the close button; a photo
    is rotated 90° whenever its orientation mismatches the viewport
    (landscape photo on portrait screen and vice versa), using `dims` from
    manifest.json; re-fits on viewport resize/orientation change
- **Thumbnail slideshows**: Crossfade transitions (no flash)
- **Header background slideshow**: Random images (whole collection, Photos/
  thumbs) crossfade every 8s behind the header text (black text-shadow for
  readability); portrait images (via `dims`) are rotated -90° by swapping
  the img box to headerH×headerW and centering it, so the long edge fills
  the header width; re-fits on window resize
- **URL sharing**: Deep-linkable state via hash

## JavaScript Architecture (index.html)


### URL State Management
- `stateToHash()` - serializes state to URL hash
- `hashToState()` - restores state from URL hash
- `pushState()` - updates browser history
- `popstate` listener - handles back/forward navigation

### Data Helpers
| Function | Purpose |
|----------|---------|
| `getTreeNode()` | Returns tree node at `currentPath` |
| `getMeteoritesBelow(path)` | Filters meteorites under a category path |
| `searchMeteorites()` | Filters by `searchNameQuery` (name only, word-start match) and `searchDescQuery` (description only, substring); both must match when both set |
| `hasSearchQuery()` | True if either search field is non-empty |
| `sortMeteorites(list)` | Sorts by category path, name, or random |
| `getRandomImage(met)` | Picks random image from meteorite |
| `collectAllImages(meteorites)` | Flattens to `{src, caption}` array for lightbox |
| `toFullPath(photoSrc)` | Converts Photos/ path to Full/ path |

### Core Rendering
- `render()` - main entry, dispatches to mode-specific renderers
- `renderHierarchy()` - shows subcategories + direct meteorites with slideshow thumbs
- `renderCollapsed()` - paginated meteorite cards for current path
- `renderPhotos()` - paginated individual photo cards
- `renderSearchResults()` - collapsed-style search results
- `renderPaginatedCards/Photos()` - shared pagination logic
- `renderBreadcrumbs()` - clickable path navigation

### Card Factories
- `createCategoryCard(name, meteorites)` - subcategory card with 5s rotating slideshow (crossfade)
- `createMeteoriteCard(met, noSlideshow)` - meteorite card, optional slideshow (crossfade)

### Detail View
- `showDetail(met)` - hides grid, shows all images + description, updates URL
- `hideDetail()` - returns to grid view

### Lightbox/Slideshow
- `openLightboxForPhotos(photos, startIndex)` - opens lightbox at specific index
- `startSlideshow()` - fullscreen random slideshow from current filter (4s interval)
- `lightboxNav(dir)` / `toggleLightboxPause()` - keyboard + button controls
- `showLightbox()` - shows lightbox, initializes panzoom
- `closeLightbox()` - hides lightbox, destroys panzoom instance
- `updateLightboxImage()` - loads Full/ image, shows spinner, calculates dynamic maxZoom, initializes panzoom

### Utilities
- `escapeHtml(text)` - XSS-safe text insertion
- `encodeImagePath(path)` - encodes each path segment separately for special chars

## Gotchas

- **panzoom owns the transform**: panzoom is attached to `#lightbox-rotator` (a
  wrapper div); the 90° auto-rotation lives on the img *inside* it - if
  panzoom targeted the img directly it would overwrite the rotation, and
  panning would feel rotated to the user
- **panzoom zoomTo() needs 3 args**: `zoomTo(x, y, scale)` with missing args
  silently poisons `transform.scale` with NaN (its guard only checks NaN,
  not undefined) and every later `zoomAbs()` throws "zoom requires valid
  numbers"; reset with `moveTo(0, 0)` + `zoomAbs(0, 0, 1)` instead
- **Crossfade slideshows**: Two overlapping `<img>` elements swap roles via reference swap (not src swap) to avoid flash
